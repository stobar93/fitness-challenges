# Fitness challenges (Retos fitness)

App móvil para participar en retos de running dentro de la ciudad, con leaderboard por reto y premios para los mejores puestos.

Ciudad de lanzamiento: **Cali, Colombia**.

## La idea

- Los usuarios pagan una **suscripción mensual**; cada plan permite un número limitado de retos.
- Cada reto tiene su **leaderboard** y, al cerrar, premia a los primeros puestos.
- De vez en cuando hay **eventos especiales con premios** mayores.
